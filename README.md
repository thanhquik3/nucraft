# NUCRAFT (BUILD v124)

Game sandbox voxel fanmade chơi trực tiếp trên trình duyệt hoặc tải thành **1 file App PC (`.EXE`) duy nhất** cho Windows.

## Chơi Trực Tiếp Trên Web (PC & Mobile)
- Mở ngay tại: **https://quythanhdz374-spec.github.io/nucraft/**

## Tải App PC (Windows — 1 File `.EXE` Duy Nhất)
- **Tải trực tiếp (GitHub Releases):** [NUCRAFT.exe (v1.0.124)](https://github.com/quythanhdz374-spec/nucraft/releases/latest/download/NUCRAFT.exe)

### Cách chơi App PC
1. Tải 1 file **`NUCRAFT.exe`** (~2.3 MB) về bất kỳ thư mục nào trên máy tính Windows.
2. Nháy đúp chuột vào **`NUCRAFT.exe`** để mở game ngay dạng cửa sổ App PC — **không cần giải nén, không cần cài Node.js hay file đi kèm**. Thế giới đã lưu được giữ bền vững trong `%LOCALAPPDATA%\NUCRAFT`.

> **Lưu ý Windows SmartScreen (lần mở đầu tiên):** Nếu Windows hiện cảnh báo bảo vệ ứng dụng mới, bấm **More info (Thông tin thêm) → Run anyway (Vẫn chạy)**.

Mã nguồn launcher PC công khai tại [`launcher/NucraftLauncher.cs`](launcher/NucraftLauncher.cs).
